1. Tổng quan đề tài

Đề tài hướng đến xây dựng hệ thống hỗ trợ lái xe có khả năng phát hiện dấu hiệu buồn ngủ thông qua mắt. Hệ thống sử dụng camera để theo dõi mắt theo thời gian thực, sau đó kết hợp thuật toán xử lý ảnh và mô hình AI để xác định người lái có đang buồn ngủ hay không.

Input

Camera realtime

Webcam lấy từng frame liên tục bằng OpenCV để đưa vào pipeline xử lý.

Processing

MediaPipe + EAR + AI

MediaPipe xác định điểm mắt, EAR đo độ mở mắt, model AI phân loại Open/Closed.

Output

Cảnh báo

Khi nhắm mắt lâu hoặc chớp mắt quá nhiều trong thời gian ngắn, hệ thống phát alarm.

4. EAR là gì?

EAR là chỉ số hình học dùng để đo mắt đang mở hay nhắm dựa trên khoảng cách giữa các landmark quanh mắt.

Công thức

EAR = (|p2-p6| + |p3-p5|) / (2 × |p1-p4|)

Hai khoảng cách dọc thể hiện độ mở mắt. Khoảng cách ngang là độ rộng mắt. Khi nhắm mắt, khoảng cách dọc giảm mạnh nên EAR giảm.

Ngưỡng thực nghiệm

Dựa trên quá trình test:

Mắt mở:  0.32 - 0.40
Mắt nhắm: 0.07 - 0.18

EAR_THRESHOLD = 0.22

Ngưỡng này cần chỉnh theo từng người, camera, ánh sáng và khoảng cách với webcam.

5. Phần model AI

Model AI dùng để đáp ứng yêu cầu có train data trong đồ án, đồng thời hỗ trợ xác nhận trạng thái mắt.

Dataset gồm hai class chính: Open và Closed. Mỗi class nên có nhiều ảnh ở các điều kiện khác nhau như sáng/tối, có kính, không kính, gần/xa camera.
Model có thể sai nếu crop mắt lệch, ánh sáng xấu hoặc dataset chưa đủ đa dạng. EAR là tín hiệu hình học đơn giản, realtime nhanh, giúp hỗ trợ model.
Nếu chỉ dùng model, hệ thống phụ thuộc hoàn toàn vào dataset. Kết hợp EAR + model giúp hệ thống ổn định hơn và giải thích được trong báo cáo.

6. Logic cảnh báo cuối cùng

Đây là phần quan trọng nhất để hệ thống đúng với đề bài: thời gian nhắm mắt lâu và tần suất nhắm mắt lớn.

Điều kiện 1

Nhắm mắt liên tục

Nếu mắt nhắm liên tục từ 2 giây trở lên, hệ thống coi là nguy hiểm và phát cảnh báo.

continuous_closed_time >= 2.0
Điều kiện 2

Chớp mắt quá nhiều

Nếu số lần chớp mắt trong 10 giây vượt ngưỡng, hệ thống cảnh báo vì có dấu hiệu mệt mỏi.

blink_rate >= 10
Điều kiện 3

Score tích lũy

Score tăng khi nhắm mắt, giảm từ từ khi mở mắt. Score chỉ gây alarm nếu hiện tại vẫn đang nhắm mắt.

is_closed and score >= 2.5
long_closed_alert = continuous_closed_time >= CONTINUOUS_CLOSED_THRESHOLD
blink_rate_alert = blink_rate >= BLINK_THRESHOLD
score_alert = is_closed and drowsiness_score >= DROWSINESS_SCORE_THRESHOLD

if long_closed_alert or blink_rate_alert or score_alert:
    start_alarm()
else:
    stop_alarm()

8. Code lõi cần nhớ

Chọn tab để xem các đoạn code quan trọng trong project.

EAR_THRESHOLD = 0.22

CONTINUOUS_CLOSED_THRESHOLD = 2.0
DROWSINESS_SCORE_THRESHOLD = 2.5
MODEL_CONFIDENCE_THRESHOLD = 0.80

BLINK_WINDOW_SECONDS = 10
BLINK_THRESHOLD = 10
def calculate_ear(eye_points):
    p1, p2, p3, p4, p5, p6 = eye_points

    vertical_1 = euclidean_distance(p2, p6)
    vertical_2 = euclidean_distance(p3, p5)
    horizontal = euclidean_distance(p1, p4)

    if horizontal == 0:
        return 0

    ear = (vertical_1 + vertical_2) / (2.0 * horizontal)
    return ear
def predict(self, image):
    img = cv2.resize(image, (224, 224))
    img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
    img = img.astype(np.float32)
    img = (img / 127.5) - 1
    img = np.expand_dims(img, axis=0)

    prediction = self.model.predict(img, verbose=0)
    index = np.argmax(prediction)

    label = self.labels[index]
    confidence = prediction[0][index]

    return label, confidence
is_closed = (
    ear < EAR_THRESHOLD
    or (
        model_label == "Closed"
        and model_conf >= MODEL_CONFIDENCE_THRESHOLD
    )
)

if is_closed:
    drowsiness_score += delta_time * 1.0
else:
    drowsiness_score -= delta_time * 0.5

drowsiness_score = max(0.0, drowsiness_score)

long_closed_alert = continuous_closed_time >= CONTINUOUS_CLOSED_THRESHOLD
blink_rate_alert = blink_rate >= BLINK_THRESHOLD
score_alert = is_closed and drowsiness_score >= DROWSINESS_SCORE_THRESHOLD

if long_closed_alert or blink_rate_alert or score_alert:
    start_alarm()
else:
    stop_alarm()

9. Dàn ý báo cáo gợi ý

  • Chương 2: Cơ sở lý thuyết: OpenCV, MediaPipe, EAR, CNN, Teachable Machine.

  • Chương 5: Kết quả thực nghiệm, đánh giá, hạn chế, hướng phát triển.

Nên nhấn mạnh khi thuyết trình

  • Hệ thống không chỉ dùng model AI, mà kết hợp thêm EAR để ổn định hơn.
  • Có ba tiêu chí cảnh báo: nhắm lâu, chớp nhiều, score tích lũy.
  • Score không reset ngay khi mở mắt, giúp phát hiện trạng thái lim dim.
  • Đã có debug crop mắt để kiểm tra model đang nhìn đúng vùng ảnh.
